# Clarity Health Interview Cheat Sheet

Use this for quick revision. Read the full [`INTERVIEW_GUIDE.md`](INTERVIEW_GUIDE.md) when learning the details.

## Elevator Pitch

> Clarity Health converts laboratory PDFs into structured, human-reviewed dashboards. PyMuPDF extracts page text, Gemini maps it into a strict Pydantic schema, the backend verifies evidence and calculates status deterministically, and users confirm every result before dashboard or assistant use.

## Architecture

```text
Next.js UI
  -> FastAPI
  -> PyMuPDF
  -> Gemini structured output
  -> Pydantic validation
  -> evidence verification
  -> Python status calculation
  -> human review
  -> dashboard, 3D map, chat, nearby care
```

## Most Important Design Choice

> AI handles ambiguous language. Normal code handles exact rules.

Examples:

- Gemini extracts `Glucose`, `105`, `mg/dL`, and `70-99`.
- Python decides `105 > 99`, therefore status is `high`.
- The user confirms the extraction before it becomes dashboard truth.

## Hallucination Controls

1. Strict Pydantic schema- what is pydantic? It is a Python library for data validation and settings management using Python type annotations.
2. `null` for missing values
3. Source page and exact excerpt- what is excerpt? It is the exact snippet of text from the source page that supports the extracted data.
4. Backend verifies excerpt exists on page
5. Python calculates status
6. Human confirms or excludes each result
7. Chat accepts confirmed results only
8. Report citations must match supplied test names
9. PubMed/MedlinePlus URLs are generated by code, not AI

Say: “I reduce and detect hallucinations.”

Do not say: “I eliminate hallucinations.”

## Main Tradeoffs

- Gemini is fast to integrate but adds cloud privacy, cost, and availability concerns.
- PyMuPDF is fast for digital PDFs but scanned PDFs need OCR.
- Human review adds friction but prevents silent AI errors.
- Local educational content is reliable and free; AI is reserved for custom questions.-> education content is inputed manually not by ai? is it true? Yes, local educational content is manually inputted to ensure reliability and accuracy, whereas AI is used for generating responses to custom questions.
- OpenStreetMap is free but has incomplete facilities and no reliable review scores.
- The health rating is transparent but not clinically validated. -> used python to make calculations based on confirmed values and predefined rules.

## Safety Statement

> This is an educational prototype using synthetic or de-identified reports. It compares confirmed values with the laboratory's printed intervals but does not diagnose, prescribe treatment, determine urgency, or claim regulatory compliance.

## Five-Minute Demo

1. State the user problem.
2. Upload the synthetic PDF.
3. Explain page-preserving PyMuPDF extraction.
4. Confirm cloud processing and run Gemini extraction. -> Explanation: cloud processing involves sending the PDF to a remote server for analysis, and Gemini extraction is the AI model that identifies and extracts relevant data from the report.
5. Show Pydantic, evidence checks, and null handling.-> pydantic is used to enforce strict schema validation, ensuring that the extracted data conforms to the expected types and constraints.
6. Edit one value and show deterministic status recalculation.
7. Confirm all or exclude one result.
8. Show dashboard counts and range plots.
9. Click Glucose or TSH to show multiple 3D body regions.
10. Open Learn & ask; show local education and trusted references.
11. Ask the overall report assistant a grounded question.
12. Switch language and show Arabic RTL or Telugu.
13. Open nearby care and disclose ratings limitations.
14. End with evaluation and OCR as next steps.

## Likely Questions

**Why no RAG?**

One small structured report fits directly in context. Retrieval adds complexity without enough benefit yet. -> my future scope is to explore retrieval-augmented generation (RAG) for handling larger or more diverse sets of reports. and give answers based on retrieved context.

**Why no agent?**

The workflow is fixed and safer as a deterministic pipeline. -> i am using AI agent in chatbots, right? Yes, AI agents are used in chatbots to handle dynamic interactions, but the core report processing remains deterministic for safety and reliability.

**Why human review?**

Schema-valid AI output can still be factually wrong.

**How would you add OCR?**

Try native text first, OCR only empty pages, store provenance, and require review.

**Is it HIPAA compliant?**

No claim. Production compliance requires technical, legal, contractual, and operational controls.

**How would you evaluate it?**

Golden synthetic reports; measure field accuracy, recall, invented results, source accuracy, latency, and cost.

**What would you improve first?**

Evaluation across diverse report layouts, then OCR fallback.
